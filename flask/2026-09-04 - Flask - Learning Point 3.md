# Extensions Fill Gaps — Flask Itself Is Bare

Flask-SQLAlchemy adds database ORM. Flask-Login adds authentication. Flask-RESTful builds REST APIs. Flask-Bcrypt hashes passwords. Each extension integrates with Flask's app pattern but is maintained independently. This keeps the core small and stable.

## Key Takeaway
Flask's extension ecosystem lets you build exactly what you need — start bare and add Flask-SQLAlchemy, Flask-Login, or Flask-RESTful as requirements grow.

## 中文：擴展功能填補空白 — Flask 本身很精簡

Flask-SQLAlchemy 加入資料庫 ORM。Flask-Login 加入認證功能。Flask-RESTful 構建 REST API。Flask-Bcrypt 雜湊密碼。每個擴展都與 Flask 的應用程式模式整合，但各自獨立維護。這樣保持核心小而穩定。

### 核心要點
Flask 的擴展生態系統讓你按需構建 — 從精簡開始，隨著需求增長再加入 Flask-SQLAlchemy、Flask-Login 或 Flask-RESTful。
