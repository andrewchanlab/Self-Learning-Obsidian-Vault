# Flask Is a Micro Framework — Minimal Core, Maximal Flexibility

Flask gives you a WSGI application, routing, and a Jinja2 template engine. Everything else is optional. Unlike Django (which has an ORM, auth, admin panel built-in), Flask lets you choose your own database, auth system, and serialization layer. This makes Flask ideal for microservices and APIs.

## Key Takeaway
Flask's minimalist core means you choose exactly which components to add — no bloat, no opinions forced on you.
