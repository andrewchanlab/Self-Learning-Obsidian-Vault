# RADIUS Handles All Three AAA Functions

Authentication answers "Who are you?" (verifying credentials). Authorization answers "What can you do?" (which network segments you can reach). Accounting answers "What did you do?" (logging connection duration and bandwidth used). Enterprise networks need all three for compliance and auditing.

## Key Takeaway
RADIUS's three A's — Authentication, Authorization, and Accounting — provide a complete picture of network access for security and compliance.
