# FreeRADIUS — The Open Source RADIUS Implementation

## English

FreeRADIUS is the most widely deployed open-source RADIUS server, powering millions of networks. It supports all major RADIUS features: PAP/CHAP/EAP authentication, proxying, dynamic authorization (CoA), and RadSec. It's incredibly configurable via its raddb/ directory of plain-text configuration files — modules, virtual servers, and policies are all editable. While powerful, this flexibility also means complex setups can become hard to maintain without proper documentation. It's the Apache of the RADIUS world.

### Key Takeaway
Advanced RADIUS features — Access-Challenge, CoA, RadSec, and device authentication — extend the protocol from simple password checking into a full-featured zero-trust access control platform.

## 中文

FreeRADIUS 是部署最廣泛的開源 RADIUS 伺服器，為數百萬個網絡提供支持。它支援所有主要 RADIUS 功能：PAP/CHAP/EAP 認證、代理、動態授權（CoA）和 RadSec。它通過 raddb/ 目錄中的純文本配置文件實現極度靈活的配置——模組、虛擬伺服器和策略都可以編輯。然而，這種靈活性也意味著複雜的設置如果沒有適當的文檔會變得難以維護。它被稱為 RADIUS 世界的 Apache。

### 重點摘要
高級 RADIUS 功能——Access-Challenge、CoA、RadSec 和設備認證——將協議從簡單的密碼檢查擴展為功能完整的零信任訪問控制平台。
