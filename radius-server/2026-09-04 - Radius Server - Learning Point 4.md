# Still Going Strong Since the 1990s

RADIUS dates back to dial-up internet days (1992) and remains the standard for WPA2-Enterprise WiFi, VPN connections, and VoIP phone systems. Its longevity comes from a simple, extensible design — new authentication methods (EAP types) are added as plugins without changing the core protocol.

## Key Takeaway
Despite its age, RADIUS remains the de facto standard for enterprise network access control because its design is both simple and extensible.
