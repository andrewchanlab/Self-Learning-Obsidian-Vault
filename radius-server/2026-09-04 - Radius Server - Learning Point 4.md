# Still Going Strong Since the 1990s

## English

RADIUS was invented in **1992** for dial-up internet and remains the de facto standard for enterprise network access today. You'll find it protecting:
- **WPA2-Enterprise WiFi** — the secure alternative to shared WiFi passwords
- **VPN connections** — corporate remote access
- **VoIP phone systems** — controlling who can make calls
- **Switch port security** — wired network access in offices

Why hasn't RADIUS been replaced? Its design is **simple yet extensible**. The core protocol handles the AAA conversation, while authentication methods (PAP, CHAP, EAP types) are pluggable modules. New security methods like EAP-TLS (certificate-based) or PEAP (password-based with server certificates) were added without changing the core RADIUS architecture.

### Key Takeaway
Despite its age, RADIUS remains the de facto standard for enterprise network access control because its design is both simple and extensible.

## 中文

RADIUS 在 **1992 年**為撥號上網而發明，至今仍是企業網絡訪問的事實標準。你會發現它在保護：
- **WPA2-Enterprise WiFi**——共享 WiFi 密碼的安全替代方案
- **VPN 連接**——企業遠程訪問
- **VoIP 電話系統**——控制誰可以打電話
- **交換機端口安全**——辦公室的有線網絡訪問

為什麼 RADIUS 沒有被取代？因為它的設計**簡單卻可擴展**。核心協議處理 AAA 對話，而認證方法（PAP、CHAP、EAP 類型）是可插拔模組。新的安全方法如 EAP-TLS（基於證書）或 PEAP（基於密碼但有伺服器證書）可以在不改變核心 RADIUS 架構的情況下添加。

### 重點摘要
儘管歷史悠久，RADIUS 仍然是企業網絡訪問控制的事實標準，因為它的設計既簡單又可擴展。
