# HSM Interfaces — PKCS#11, JCE, REST APIs

Applications interact with HSMs through standard interfaces. PKCS#11 is the most common — a cross-platform API for cryptographic operations. Java applications use JCE (Java Cryptography Extension). Cloud HSMs often provide REST APIs. Thales, Utimaco, and AWS CloudHSM are popular HSM vendors. FIPS 140-2 Level 3 certification is the standard security benchmark for enterprise HSMs.

## Key Takeaway
HSMs use standardized interfaces (PKCS#11, JCE) so applications can switch HSM vendors without code changes.
