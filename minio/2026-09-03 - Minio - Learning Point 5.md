# MinIO Clients Use mc (MinIO Client) for Bucket and Object Management

The `mc` CLI tool is your primary interface for managing MinIO deployments. With `mc alias set`, you connect to any S3-compatible server. Then `mc ls`, `mc cp`, `mc mb`, `mc policy` let you list, copy, create buckets, and manage access policies. It is designed to feel familiar to AWS CLI users but works with any S3 endpoint.

## Key Takeaway
The `mc` CLI manages MinIO buckets and objects via familiar S3-style commands.

## 核心要點
