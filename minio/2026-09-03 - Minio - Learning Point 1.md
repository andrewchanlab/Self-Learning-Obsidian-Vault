# MinIO Is an S3-Compatible Object Storage Server

MinIO is a high-performance object storage server that implements the Amazon S3 API. This means any tool built for S3 — boto3, s3cmd, rclone, Cyberduck — works with MinIO out of the box. You get enterprise-grade object storage without vendor lock-in, deployable on any infrastructure from a laptop to a Kubernetes cluster.

## Key Takeaway
MinIO is an S3-compatible object storage server.

- Amazon S3

# MinIO 是一個 S3 相容的對象存儲服務器

MinIO 是一個高性能對象存儲服務器，實現了 Amazon S3 API。這意味著任何為 S3 構建的工具——boto3、s3cmd、rclone、Cyberduck——都能直接使用 MinIO。你可以在任何基礎設施上部署企業級對象存儲，從筆記本電腦到 Kubernetes 集群，無需擔心供應商鎖定。

## 核心要點
MinIO 是一個 S3 相容的對象存儲服務器。
