# NestJS Uses Modular Architecture Like LEGO Blocks

A NestJS application is a tree of modules. Each module encapsulates related controllers, services, and providers. A UsersModule handles user features; an OrdersModule handles order features. This makes large applications manageable — modules are developed and tested independently, then snapped together.

## Key Takeaway
NestJS's modular architecture organizes code into self-contained, testable units that compose into a complete application.
