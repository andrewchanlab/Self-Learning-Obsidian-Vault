# Framework-Agnostic Zero-Config Setup

Vite works with React, Vue, Svelte, Solid, or vanilla JS without any configuration. Drop in a .html file and run `vite` — you have a dev server. This minimal config philosophy makes it accessible while still powerful enough for production apps.

## Key Takeaway
Vite's zero-config defaults work out of the box, but its plugin system scales to handle complex production requirements when needed.

## Related Concepts
- Plugin System
- Framework Agnostic
- Zero Config

# 框架無關的零配置設置

Vite 無需任何配置即可與 React、Vue、Svelte、Solid 或原生 JS 配合使用。只要放一個 .html 文件，運行 `vite`——就有了一個開發伺服器。這種極簡配置理念使其易於上手，同時又足夠強大以滿足生產應用的需求。

## 核心要點
Vite 的零配置默認值開箱即用，但其插件系統可擴展以處理複雜的生產需求。

## 相關概念
- 插件系統（Plugin System）
- 框架無關（Framework Agnostic）
- 零配置（Zero Config）
