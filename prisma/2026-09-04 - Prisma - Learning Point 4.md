# Prisma Studio — Built-In Visual Data Browser

Running `npx prisma studio` opens a browser-based table viewer at localhost:5555. Browse tables, filter, edit, and delete records. No external database GUI tool needed during development — it's built into the framework.

## Key Takeaway
Prisma Studio provides a zero-setup visual database browser for quick data inspection and debugging during development.
