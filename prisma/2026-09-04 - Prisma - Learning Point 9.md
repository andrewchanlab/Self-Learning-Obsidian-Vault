# Prisma Accelerate — Global Database Edge Cache

Prisma Accelerate is a managed edge cache that sits in front of your Prisma database. It caches query results at the edge, reduces database load, and adds connection pooling. Configure `prisma-client-extensions` or use the Accelerate URL in your connection string — queries to cached data return in milliseconds worldwide.

## Key Takeaway
Accelerate makes Prisma production-ready at scale: edge caching, connection pooling, and global low-latency reads without changing your application code.

## 中文：Prisma Accelerate — 全球數據庫邊緣緩存

Prisma Accelerate 是一個托管的邊緣緩存，位於你的 Prisma 數據庫前面。它在邊緣緩存查詢結果，減少數據庫負載，並添加連接池。在連接字串中使用 Accelerate URL 或配置 `prisma-client-extensions` — 對緩存數據的查詢在全球範圍內以毫秒級延遲返回。

## 核心要點
Accelerate 使 Prisma 在規模上生產就緒：邊緣緩存、連接池和全球低延遲讀取，無需更改應用程序代碼。
