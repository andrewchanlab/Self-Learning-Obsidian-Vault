# MCP — A Standard Protocol for AI Tool Use

The Model Context Protocol (MCP) is an open protocol that standardizes how AI models connect to external tools and data sources. Instead of every AI application inventing its own way to call tools, MCP provides a common interface — like USB-C for AI integrations. An MCP server exposes tools (functions), and any MCP-compatible AI client can use them.

## Key Takeaway
MCP standardizes the AI-tool connection, making integrations portable — write once, use with any MCP-compatible AI client.
