# MCP Tools vs Resources vs Prompts

MCP defines three capability types: **Tools** are functions the AI can call (search web, send email, query database). **Resources** are data the AI can read (file contents, API responses). **Prompts** are reusable prompt templates. This separation lets MCP serve both active operations (tools) and passive data access (resources), making it flexible for diverse use cases.

## Key Takeaway
MCP's three capability types (Tools, Resources, Prompts) cover both active AI actions and passive data retrieval in a single protocol.
