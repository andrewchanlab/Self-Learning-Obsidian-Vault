# Encryption Scrambles Data So Only Intended Recipients Can Read It

Encryption is the process of converting plaintext (readable data) into ciphertext (garbled, unreadable data) using a mathematical algorithm and a key. Without the correct key, the ciphertext looks like random nonsense. Decryption reverses the process — turning ciphertext back into plaintext. This is the foundation of digital privacy: it protects your messages, bank details, passwords, and files from eavesdroppers.

## Key Takeaway
Encryption transforms readable data into unreadable ciphertext using algorithms and keys — only those with the correct key can reverse the process.

## 中文：加密將數據打亂，只有目標收件人能閱讀

加密就是將「明文」（你可以閱讀的原始數據）通過數學算法和密鑰轉換成「密文」（混亂、不可讀的數據）。沒有正確的密鑰，密文看起來就像隨機的垃圾。解密則是反向操作——將密文恢復成明文。這是數字隱私的基石：保護你的訊息、銀行資料、密碼和文件不被竊聽者看到。

## 核心要點
加密通過算法和密鑰將可讀數據轉換為不可讀的密文——只有持有正確密鑰的人才能逆向操作。
