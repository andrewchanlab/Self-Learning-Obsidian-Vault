# Single Codebase, Four Platforms

Flutter compiles from Dart to native ARM code for iOS, Android, web (WebAssembly/DOM), and desktop (Windows/macOS/Linux). A single codebase produces apps that look and feel native — not a webview wrapper. The tradeoff: Dart is not a mainstream language, and app bundle sizes are larger than React Native.

## Key Takeaway
Flutter's single codebase approach covers iOS, Android, web, and desktop — but requires learning Dart and accepting larger app sizes compared to cross-platform alternatives.
