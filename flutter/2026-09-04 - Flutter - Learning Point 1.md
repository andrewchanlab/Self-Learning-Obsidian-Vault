# Everything Is a Widget — Flutter's Composable UI System

In Flutter, buttons, text, images, layouts, and screens are all widgets. Widgets are nested to build a tree — a Scaffold contains an AppBar which contains a title. Compose widgets together like LEGO blocks. Flutter's widget system is fully declarative: you describe the UI, Flutter handles rendering.

## Key Takeaway
Flutter's everything-is-a-widget philosophy creates a highly reusable, composable UI system where every UI element is a self-contained building block.
