# Layout Options: st.sidebar, st.columns, and st.expander Control Visual Structure

Streamlit provides layout primitives: `st.sidebar` creates a persistent side panel for controls; `st.columns([1,2,3])` creates horizontal columns; `st.expander` collapses content behind a clickable header. These let you build polished multi-section layouts without HTML/CSS. The sidebar is the most common pattern — put all user controls there to keep the main area focused on output.

## Key Takeaway
st.sidebar, st.columns, and st.expander build polished layouts without HTML/CSS.

- st.sidebar
- st.columns
- st.expander

# 佈局選項：st.sidebar、st.columns 和 st.expander 控制視覺結構

Streamlit 提供佈局原語：`st.sidebar` 創建一個持久化的側邊面板用於控制；`st.columns([1,2,3])` 創建水平列；`st.expander` 在可點擊標題後折疊內容。這些讓你可以不使用 HTML/CSS 就能構建精緻的多區塊佈局。側邊欄是最常見的模式——把所有用戶控制放在那裡，讓主區域專注於輸出。

## 核心要點
st.sidebar、st.columns 和 st.expander 無需 HTML/CSS 即可構建精緻佈局。

## 相關概念
- st.sidebar
- st.columns
- st.expander
