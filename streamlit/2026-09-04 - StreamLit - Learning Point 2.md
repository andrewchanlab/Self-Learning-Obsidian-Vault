# Auto-Refresh Workflow — Save and See Changes

Streamlit watches your Python file. Every time you save, it reruns your script from top to bottom and updates the browser. There's no webpack bundling, no page refresh, no state loss (if you use session state). It's like a Jupyter notebook married a web framework — the best of both worlds.

## Key Takeaway
The auto-refresh development loop makes Streamlit development feel instantaneous — edit code, see changes immediately in the browser.
