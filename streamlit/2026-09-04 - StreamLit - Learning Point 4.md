# Built for Data & ML Use Cases

Streamlit integrates natively with pandas (tables), plotly/altair (charts), scikit-learn (ML metrics), and torch/tensorflow (model inference). Data exploration tools, model dashboards, and demo prototypes can be built in hours instead of weeks.

## Key Takeaway
Streamlit's native support for data science libraries makes it the go-to tool for building ML model demos and data dashboards.
