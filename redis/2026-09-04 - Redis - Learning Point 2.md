# More Than Key-Value: Rich Data Structures

Redis isn't just a fancy dictionary. It supports Strings, Lists (queues), Sets (unique collections), Hashes (user profiles), Sorted Sets (leaderboards ranked by score), Bitmaps, HyperLogLog, and Geospatial indexes. This lets you model complex data without a separate application-layer structure.

## Key Takeaway
Redis's rich data structures eliminate the need for separate application-layer data structures in many cases — the database IS your data structure server.
