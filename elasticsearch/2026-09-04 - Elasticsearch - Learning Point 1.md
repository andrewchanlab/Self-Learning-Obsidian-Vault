# Elasticsearch Is a Search Engine, Not a Database

Databases store and retrieve records by ID or indexed field. Elasticsearch stores documents and answers complex analytical queries — "find all posts about pizza in Tokyo written last week with photos attached." It's built on Apache Lucene and is the backbone of the ELK stack for log analytics.

## Key Takeaway
Elasticsearch is optimized for search and analytics workloads, not transactional data — treat it as a search engine, not your system of record.
