# Typo Tolerance Built Into the Core

Meilisearch handles typos automatically — "reciept" finds "receipt", "resturant" finds "restaurant". Ranking rules are customizable but work out of the box. Search results appear in under 50ms, often before the user finishes typing.

## Key Takeaway
Typo tolerance is a first-class feature in Meilisearch — no extra configuration needed, it works out of the box.
