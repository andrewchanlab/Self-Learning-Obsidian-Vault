# Zero-Config with Sensible Defaults

Meilisearch works out of the box with sensible defaults: field types are auto-detected, indexing happens automatically, and a beautiful dev dashboard appears at localhost:7700. POST JSON documents, immediately search them.

## Key Takeaway
Meilisearch's zero-config defaults mean you can go from install to working search in under 5 minutes.
