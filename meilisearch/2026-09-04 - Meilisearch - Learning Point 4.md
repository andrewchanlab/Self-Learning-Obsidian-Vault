# Real-Time Search-as-You-Type by Default

Meilisearch was designed for the modern UX where results update on every keystroke. It powers search experiences where results appear before the user finishes typing. For small-to-medium datasets under 10 million documents, it replaces Elasticsearch with a fraction of the complexity.

## Key Takeaway
Meilisearch's search-as-you-type UX is built into its core architecture — not an afterthought plugin.

## 中文：默认的实时边打字边搜索体验

Meilisearch 从设计上就为现代用户体验而生——每次按键结果都会更新。它实现的搜索体验是：用户还没打完字，结果就已经出现了。对于 1000 万文档以下的中等规模数据集，Meilisearch 可以用极低的复杂度替代 Elasticsearch。

## 核心要点
Meilisearch 的"边打字边搜索"用户体验是内置于核心架构的——不是后期插件。
